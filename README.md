# Todo-web-application

## Description
This is a simple learning project built using **JavaScript DOM Manipulation**. 
It allows users to **add tasks** and **delete tasks** dynamically. 
This project helped me practice DOM methods, event handling, and basic JavaScript concepts.

## Features
- Add tasks dynamically
- Delete tasks
- Interactive UI using JavaScript

## Technologies Used
- HTML
- CSS
- JavaScript (DOM Manipulation)

## How to Use
1. Clone or download the repository
2. Open `index.html` in a web browser
3. Add tasks using the input field
4. Delete tasks by clicking the delete button
